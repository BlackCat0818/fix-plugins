# 原Addon版本ScriptAPI存在的缺陷

## 实体识别问题
- **假人过滤缺陷**  
  未区分真实玩家与假人，导致假人死亡也会生成墓碑

## 物品处理缺陷
- **物品白名单机制缺失**  
  收纳袋内物品保存异常
- **消失诅咒处理缺陷**  
  带有消失诅咒附魔的盔甲仍会出现在墓碑中
- **特殊标签兼容问题**  
  未正确处理以下标签：
  - 死亡不掉落(`keep_on_death`)
  - 锁定物品栏(`item_lock`)

## 墓碑生成缺陷
- **特殊位置死亡处理不当**  
  死在不完整方块（下界传送门框架/床）上时：
  - 会直接摧毁原有方块
  - 应改为以死亡位置为中心，10格半径搜索可用空间生成墓碑
- **多实体位置冲突**  
  墓碑位置存在多个实体时出现异常（LSE环境下100%复现）

## 功能实现缺陷
- **副手持钥匙功能缺失**  
  钥匙在副手时不显示墓碑位置和距离信息
- **墓碑有效期管理缺陷**  
  - 缺乏可自定义的有效时长设置（默认10分钟）
  - 未解决服务器重启后的时间延续问题
- **防推机制失效**  
  墓碑可能被活塞推动

# LSE版本墓碑插件 技术细节与问题说明

## 核心机制说明
- **防爆机制**：
  - `destructible_by_explosion: false` 表示墓碑无法被爆炸破坏
- **实体标识符**：
  - `identifier: "entity:grave_inventory"`（墓碑实体唯一标识）
- **玩家标识系统**：
  - `Tags: ["-8589934591"]` 存储玩家唯一标识符（string类型）
  - `-8589934591` 对应玩家实体的 uniqueId

## Addon 与 LSE 等效操作对照
| Addon 操作                                                                   | LSE 等效操作          | 功能说明         |
| ---------------------------------------------------------------------------- | --------------------- | ---------------- |
| `block.setPermutation(block.permutation.withState("block:destructible", 0))` | 修改方块NBT中的states | 设置方块防爆属性 |
| `dimension.getEntitiesAtBlockLocation({ x, y, z })`                          | `mc.getEntities()`    | 获取指定位置实体 |

## 实体获取方法
```javascript
// 获取范围内的实体
mc.getEntities(startPos[, range])
mc.getEntities(startPos, endPos[, range])

// 参数说明
startPos : IntPos / FloatPos   // 起始坐标
endPos : IntPos / FloatPos     // 终止坐标
range : Number                 // 搜索范围

// 返回值
Array<Entity,Entity,...>      // 实体对象列表

// 通过ID获取实体
mc.getEntity(info)  // info: UniqueId/RuntimeId
// 返回: Entity对象 (失败返回Null)
```
