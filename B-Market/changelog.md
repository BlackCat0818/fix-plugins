# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.3.0]
### Added
- 添加批量购买、批量上架、补货功能、添加日志记录

## [0.2.6]
### Fixed
- 修复上传物品到店铺后数量为0时客户端仍显示1个物品的bug（例如：背包内64个苹果全部上传后，背包内仍显示剩余一个苹果，实际已不存在）

## [0.2.5]
### Added
- 支持根据商品名称模糊搜索商品

## [0.2.4]
### Added
- 商品数据增加上架时间字段
### Changed
- 查看全部商品按商品类型进行排序
- 优化附魔书显示，直接展示附魔属性而非通用物品名

## [0.2.3]
### Changed
- 上架商品单价上限调整为 999999999

## [0.2.2]
### Added
- 查看交易记录功能
- 一键上架背包内全部物品
- 上架商品时支持编辑商品备注
- 编辑商品时支持修改商品备注
- 编辑店铺信息时支持修改店铺名称
- 店铺排行榜（支持按平均每笔交易额、营业额、交易次数排序）

## [0.2.1]
### Added
- 支持自定义禁止上架的物品列表
- 编辑店铺信息（宣传语等）
- 所有玩家提示语增加插件前缀 `§6[Market] §r`

## [0.2.0]
### Added
- 下架商品
- 编辑商品（价格、备注等）
- 一键开店
- 一键关店

## [0.1.0]
### Added
- 上架商品
- 购买商品
