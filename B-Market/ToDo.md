# 市场 插件 功能概述

## 项目基本信息

- **插件类型**: 运行在 BDS with LeviLamina with legacy-script-engine-quickjs-JavaScript 市场插件


> Version **0.1.0**
- [×] 上架商品
- [×] 购买商品


> Version **0.2.0**
- [×] 下架商品
- [×] 编辑商品
- [×] 一键开店
- [×] 一键关店


> Version **0.2.1**
- [×] 自定义禁止上架的物品
- [×] 编辑店铺信息
- [×] 提示语增加插件前缀


> Version **0.2.2**
- [×] 增加查看交易记录功能
- [×] 上架商品时支持一键上架背包内全部物品
- [×] 上架商品时支持编辑商品备注
- [×] 编辑商品时支持修改商品备注
- [×] 编辑店铺信息时支持修改店铺名称
- [×] 主表单增加按钮：店铺排行榜（营业额除以交易次数的概念被称为“平均每笔交易额”或者“平均交易金额”）根据平均交易金额或营业额或交易次数进行排序


> Version **0.2.3**
- [×] 上架商品单价最大 999999999


> Version **0.2.4**
- [×] 查看全部商品按照商品类型进行排序
- [×] 查看全部商品时针对附魔书显示进行优化（直接显示附魔属性）
- [×] 商品数据增加上架时间


> Version **0.2.5**
- [×] 支持根据商品名称模糊搜索商品

> Version **0.2.6**
- [×] 修复了一个潜在问题：上传物品到店铺中后如果被扣除后的物品数量为0可能会显示为1个物品但实际不存在的bug
（例如：背包内64个苹果全部上传到店铺后背包内还显示剩一个苹果，重进后正常，因为这个物品nbt内的数量是0，但客户端这边已经不存在这个物品了）


> Version **0.3.0**
- [ ] 上架商品时指定该商品仅可被指定玩家购买
- [ ] 卷铺跑路
- [ ] 创建店铺时起名时支持检查违禁词
- [ ] 宣传语检查违禁词
- [ ] 商品备注检查违禁词



## 总结
当前项目已完成大部分功能，包括上架商品、购买商品。未完成的功能主要集中在 店铺排行榜、卷铺跑路、编辑店铺信息时支持修改店铺名称 等方面。

已完成和未完成功能用 [×] 表示已完成，[ ] 表示未完成。
